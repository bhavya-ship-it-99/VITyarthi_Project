# Project Statement

## 1. Problem Statement

E-commerce websites have a lot of sales data like orders, customers, products, sales, profit, cities, categories, payment methods etc.

Checking all this data manually can take more time and can also be confusing.

This project is made to analyse e-commerce sales data using Python and Pandas. It gives useful info about total sales, total profit, top products, sales by city, monthly sales and payment methods.

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 2. Scope of the Project

The main scope of this project is to perform basic analysis of e-commerce sales data.

The project can:

* Calculate total sales
* Calculate total profit
* Count total orders
* Count total customers
* Show sales by category
* Find top 10 products
* Show sales by city
* Show monthly sales
* Analyse payment methods
* Show profit by category
* Display complete sales data
* Filter data by category
* Filter data by city
* Reset filters

The project is currently **console-based** and runs through the Command Prompt / Terminal. No GUI is used.

----------------------------------------------------------------------------------------------------------------------------------------------------------

## 3. Target Users

This project can be useful for:

* Students learning basic data analysis
* Small businesses for basic sales analysis
* Users who want to understand sales data

--------------------------------------------------------------------------------------------------------------------------------------------------

## 4. High-Level Features

### KPI Analysis

Shows basic information such as:

* Total Sales
* Total Profit
* Total Orders
* Total Customers

### Sales by Category

Shows the total sales for each product category.

### Top Products

Shows the top 10 products based on their sales.

### Sales by City

Shows the total sales for different cities.

### Monthly Sales

Shows total sales according to the month of the order.

### Payment Method Analysis

Shows sales based on payment methods such as:

* UPI
* Cash
* Credit Card

### Profit by Category

Shows the total profit generated by each category.

### Data Filtering

The user can filter the data based on:

* Category
* City

### Reset Filters

The user can remove the applied filters and return to the complete data.
